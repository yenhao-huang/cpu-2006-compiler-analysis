- Headless Chromium 1248 via `render.mjs` (DevTools pipe): 12 slides, all 4 font faces `loaded`, 12 screenshots at 1920×1080 and one 390×844 phone viewport (stage letterboxed, no reflow).

- PDF: 12 pages, one slide per page, backgrounds printed, text extractable on every page (pypdf); pages 1, 6, 9 rasterized with PyMuPDF and inspected.

## Environment notes

- This host has no system fonts or fontconfig. Chromium then rejects web fonts once text is laid out (`NetworkError`); rendering needs `FONTCONFIG_FILE` pointing at a config whose `<dir>` holds the TTFs (here `build/fonts`). Ordinary desktop browsers are unaffected.
- Chromium runtime libraries were extracted with `apt-get download` + `dpkg-deb -x` into a scratch directory (`LD_LIBRARY_PATH`); nothing was installed system-wide.
- In Noto Sans TC Regular, a subset containing extra symbols beyond the slide text was rejected by Chromium; the generator subsets Noto to the visible slide text only and replaces U+FF5E with an en dash.
